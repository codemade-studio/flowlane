# Flowlane — concept SaaS landing page

A fictional SaaS landing page built as a portfolio concept by [Codemade Studio](https://codemade.studio).
All companies, people, and product details are made up.

Stack: React 19 · Vite · Tailwind CSS 4 · Inter.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build to dist/
```

Deploy on Vercel: import the repo, framework preset **Vite** (build `npm run build`, output `dist`).
